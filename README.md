# 自定义背景

为 Codex 设置透明背景、随机图片、远程图片或本地图片，并在独立的“自定义背景”设置页中管理显示效果。

## 功能

- 支持透明背景、随机图片、远程图片 URL 和本地图片
- 透明背景可继续使用颜色遮罩、界面控件磨砂和窗口底层磨砂
- 保存当前背景及最近使用记录
- 提供遮罩、模糊和可拖动的背景快捷按钮
- 快捷按钮悬停后向上展开，可暂停背景、切换背景模糊或直接进入本包设置页
- 随机图片模式点击主按钮会切换图片；远程、本地或未选择来源时点击会打开设置页

## 安装

下载或克隆本仓库后，将本目录作为本地功能包导入 Codex Tweaks。首次安装后需检查权限、完成编译并手动启用。

## 权限与安全

- Renderer：修改 Codex 页面背景和设置界面，并在浏览器本地存储中保存背景配置
- Node：代理远程图片请求、解析重定向并读取需要保存的远程图片内容
- 网络：访问用户填写的图片地址，以及随机图片服务 `t.alcy.cc` 和 `tc.alcy.cc`

## 兼容性

- Codex Tweaks API：v3
- 已测试平台：macOS
- 已知限制：依赖 Codex 当前页面结构；随机图片功能依赖第三方图片服务可用性

## 开发

运行 `npm install` 安装锁定依赖，使用 `npm test` 执行单元测试，然后在 Codex Tweaks 中重新编译并验证启用、停用和 Node 授权流程。
