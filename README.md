# 自定义背景

为 Codex 设置透明背景、随机图片、远程图片或本地图片，并在 Codex 设置的“自定义背景”页面中管理显示效果。

## 功能

- 支持透明背景、随机图片、远程图片 URL 和本地图片
- 透明背景可继续使用颜色遮罩、界面控件磨砂和窗口底层磨砂
- 保存当前背景及最近使用记录
- 提供遮罩、模糊和可拖动的背景快捷按钮
- 快捷按钮悬停后向上展开，可暂停背景、切换背景模糊或打开“自定义背景”设置页
- 随机图片模式点击主按钮会切换图片；远程、本地或未选择来源时点击会打开设置面板
- 隐藏聊天页快捷按钮后，可从 Codex 设置中的“自定义背景”入口重新进入

## 安装

下载或克隆本仓库后，将本目录作为本地功能包导入 Codex Tweaks。首次安装后需检查权限、完成编译并手动启用。

## 权限与安全

- Renderer：修改 Codex 页面背景和设置界面，并在浏览器本地存储中保存背景配置
- Node：代理远程图片请求、解析重定向并读取需要保存的远程图片内容
- 网络：访问用户填写的图片地址，以及随机图片服务 `t.alcy.cc` 和 `tc.alcy.cc`

## 兼容性

- Codex Tweaks API：v3
- 已测试平台：macOS
- 兼容 `data-theme` 与旧版 `electron-light` 主题标记
- 设置页通过 `ui.settingsSections@1` 挂载，需要已适配当前 Codex 的 Codex Tweaks；适配不可用时，快捷按钮提供备用面板，背景继续生效
- 已知限制：依赖 Codex 当前页面结构；随机图片功能依赖第三方图片服务可用性

## 开发

运行 `mise run install` 安装锁定依赖，使用 `mise run check` 检查语法、`mise run test` 运行现有逻辑测试，然后在 Codex Tweaks 中重新编译并验证主题切换、设置面板、启用、停用和 Node 授权流程。界面效果通过真实页面验证。
